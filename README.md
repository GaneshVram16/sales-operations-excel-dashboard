# Sales Operations Dashboard — Microsoft Excel

Interactive Excel portfolio project focused on sales operations reporting.

## What the workbook demonstrates
- Raw-data organization and cleaning
- Excel Tables and filters
- KPI calculations
- `SUMIFS`, `COUNTIFS`, lookup logic
- Monthly and regional summaries
- Dashboard charts
- Business-oriented reporting

## Dataset
Synthetic 2025 sales transactions with 12,000 rows covering region, salesperson, channel, category, units, sales, discounts, cost, profit and margin.

## Key KPIs
Revenue, profit, margin %, order count, average order value, monthly trend, region performance and channel performance.

## Repository files
- `Sales_Operations_Dashboard.xlsx` — completed workbook
- `dashboard_preview.png` — dashboard preview
- `generate_data.py` — reproducible synthetic-data generator
- `sample_data/sales_transactions_sample.csv` — sample source rows
- `documentation/dashboard_notes.md` — metric definitions and review notes

The dataset is synthetic and contains no private information.
