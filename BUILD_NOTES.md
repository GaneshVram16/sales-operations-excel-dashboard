# How the Excel dashboard was built

1. Load the generated sales transaction CSV into an Excel table.
2. Standardize date, numeric and percentage columns.
3. Calculate KPI summaries for Net Sales, Profit, Margin %, Orders and AOV.
4. Build summary views for month, region, channel and product category.
5. Create a one-page management dashboard with KPI cards and four charts.
6. Use conditional formatting and consistent number formats for fast review.

This repository uses synthetic data so the workbook can be shared publicly and discussed in interviews without exposing employer information.
