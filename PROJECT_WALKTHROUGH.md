# Project walkthrough

## Problem
Create a management-friendly Excel reporting workflow from transaction-level sales data.

## Workflow
1. Generate 12,000 synthetic transactions.
2. Standardize dates, currency and percentage fields.
3. Create KPI summaries for net sales, profit, margin, orders and average order value.
4. Aggregate performance by month, region, channel and category.
5. Build a one-page dashboard for quick business review.

## What to explain in a discussion
- Difference between Gross Sales and Net Sales.
- How Profit and Margin % are calculated.
- When to use SUMIFS/COUNTIFS.
- Why a dashboard should highlight a few decision-relevant KPIs rather than every metric.
- How Power Query would be used when incoming files require repeated cleaning.

## Limitation
The source data is synthetic, so the project demonstrates Excel reporting technique rather than employer results.
